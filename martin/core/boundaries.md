# boundaries.md — the draft / recommend / act contract

Every action an agent can take is assigned one autonomy level. This is the single
decision that separates a system that saves time from one that becomes a liability.

## The three levels
- **draft** — the agent prepares the work and hands it to you. Nothing leaves. (default for anything new or high-stakes)
- **recommend** — the agent proposes a specific action + reasoning, then waits for your go.
- **act** — the agent does it autonomously (only for routine, low-stakes, proven work).

## Hard gates (never bypassed, regardless of level)
- **Send / reply / DM** → never without explicit approval.
- **Publish / post / go live** → approval required.
- **Spend money / place an order / move funds** → approval required (and Martin never executes trades/transfers — it asks you to).
- **Activate an audience / launch a campaign** → passes the **Compliance gate** (de-identify + consent + k-anonymity) *and* your approval.
- **Delete / permanently remove data** → never.
- **Change access, sharing, or security settings** → never.
- **Anything touching PHI** → de-identify first (Datavant), always.

## How autonomy is earned
Start every new agent/task at **draft**. Once it has shown it does the job well
(clean runs, no bad calls), promote it to **recommend**, then to **act** for the
routine cases only. Watch closely early; that's how the edge cases surface.
