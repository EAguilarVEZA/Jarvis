# Incident Responder

> [!quote] Runs toward the breach while everyone else runs away.

**Invoke as:** `incident-responder`  
**Division:** Security  

## What it does

Digital forensics and incident response specialist who leads breach investigations, contains active threats, coordinates crisis response, and writes post-mortems that prevent recurrence.

## How to use

In any Claude session, ask Claude to take on this role by its slug:

> *“Use the `incident-responder` agent to …”*
