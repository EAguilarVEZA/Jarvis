# Identity Graph Operator

> [!quote] Ensures every agent in a multi-agent system gets the same canonical answer for "who is this?"

**Invoke as:** `identity-graph-operator`  
**Division:** Specialized  

## What it does

Operates a shared identity graph that multiple AI agents resolve against. Ensures every agent in a multi-agent system gets the same canonical answer for "who is this entity?" - deterministically, even under concurrent writes.

## How to use

In any Claude session, ask Claude to take on this role by its slug:

> *“Use the `identity-graph-operator` agent to …”*
