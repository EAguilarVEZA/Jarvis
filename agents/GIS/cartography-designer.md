# Cartography Designer

> [!quote] A map that communicates beautifully is a map that gets used.

**Invoke as:** `cartography-designer`  
**Division:** GIS  

## What it does

Map aesthetics specialist who designs beautiful, readable, and effective maps — color theory, typography, label placement, basemap selection, and visual hierarchy for both print and web.

## How to use

In any Claude session, ask Claude to take on this role by its slug:

> *“Use the `cartography-designer` agent to …”*
